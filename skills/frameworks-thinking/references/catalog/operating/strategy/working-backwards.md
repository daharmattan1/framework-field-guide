# Working Backwards / PR-FAQ (Amazon)

- **Layer / Taxon:** operating · strategy
- **Origin:** Jeff Bezos / Amazon, ~2004 — provenance `[FACT]` per Gemini, `[SIGNAL]` per ChatGPT. [self-reported: https://workingbackwards.com/concepts/working-backwards-pr-faq-process/]
- **Structure:** `Future press release (1 pg) → FAQ (≤5 pg: external + internal/economic risk) → build decision.`
- **SWOT:** **S** forces extreme customer-centricity, cheap filter to kill weak ideas early · **W** labor-intensive; needs a writing/doc-review culture · **O** adaptable by startups (Airbnb, Stripe) for PMF · **T** written as a checkbox *after* the decision ("tunnel not funnel").
- **Case study:** Amazon (AWS, Kindle, Alexa) demonstrate PR-FAQ application to mature products. [case cut 2026-07: Assemble startup case unverifiable]
- **Combine:** `OP-single-threaded-ownership` (native pairing), `OP-jtbd`, `OP-shape-up`. **Conflict:** rigid Agile feature-factories (`OP-agile-scrum`).
- **Evidence:** ⚠️ **HEADLINE CONFLICT** — Gemini `[DIRECT]` ("massive documented success"); ChatGPT `[ABSENT]→[INDIRECT]` ("mostly anecdotal"). *Adjudication: INDIRECT — the mechanism is sound but independent evidence is thin; unproven in low-trust/resource-starved orgs.* [source: https://modelthinkers.com/mental-model/amazons-working-backwards]
