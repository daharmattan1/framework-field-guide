# Agile / Scrum

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Agile Manifesto 2001; Scrum early 1990s (Schwaber/Sutherland). Pillars: transparency, inspection, adaptation. [source: https://www.scrum.org/resources/agile-manifesto]
- **Structure:** `Backlog → Sprint Planning → Sprint (+ Daily Standup) → Review/Retro → repeat.`
- **SWOT (combined Agile/Scrum/Kanban):** **S** radical adaptability, rapid feedback, working increments · **W** ceremonies degrade into micromanagement theater · **O** extend beyond eng into Marketing/HR · **T** "Water-Scrum-Fall" (Waterfall phases renamed Sprints).
- **Use / fails:** Software/products with changing requirements; fails for hardware/infrastructure where late changes are catastrophically expensive.
- **Case study:** *No single named company* in sources — "industry canon" + a generic cautionary (management imposes ceremonies but won't yield product authority). ChatGPT notes real-world Scrum is heavily *adapted*, not followed literally. [source: https://www.scrum.org/resources/agile-manifesto]
- **Evidence** `[DIRECT]` (undisputed standard), though rarely in pure form.
