# RITE (Rapid Iterative Testing and Evaluation)

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Michael Medlock, Microsoft Games Studios, 2002. [source: https://en.wikipedia.org/wiki/RITE_Method]
- **Structure:** `Test with 1–2 users → find severe blocker → halt, fix immediately → resume to verify.`
- **SWOT:** **S** high problems-found-to-fixes ratio, cost-effective · **W** no statistical significance, single-user anomaly risk · **O** UI/UX in Agile sprints · **T** running it without devs present = just slow testing.
- **Case study:** **Microsoft (Age of Empires II)** — built the tutorial via between-playtest fixes → acclaim for accessibility. [source: https://www.researchgate.net/publication/327526336_The_Rapid_Iterative_Test_and_Evaluation_Method_RITE]
- **Evidence** `[DIRECT]` in software/game dev.
