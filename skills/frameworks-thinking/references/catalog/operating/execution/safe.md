# SAFe (Scaled Agile Framework)

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Dean Leffingwell, Scaled Agile Inc., 2011. [self-reported: https://framework.scaledagile.com/about]
- **Structure:** `Portfolio (Lean Portfolio Mgmt) → Program (Agile Release Trains in Program Increments) → Team (Scrum/Kanban).`
- **SWOT:** **S** recognizable hierarchy comforting to Fortune-500 execs leaving Waterfall · **W** heavy on process/ceremonies/certifications, often "Agile in name only" · **O** WSJF for economic prioritization · **T** PI Planning as compliance theater kills motivation.
- **Case study — cautionary only:** widespread practitioner reports of adoptions **stalling because SAFe reinforced legacy behaviors**; senior devs decline SAFe roles citing bureaucracy. `[COI — PRACTITIONER ORG]` [source: https://link.springer.com/chapter/10.1007/978-3-030-78098-2_11]
- **Evidence** `[INDIRECT]` — strong adoption, mixed/owner-marketed outcomes. **The execution-layer cautionary case** in both sources. Seed: "cite with a raised eyebrow."
