# Lean / Toyota Production System

- **Layer / Taxon:** operating · execution
- **Coverage note:** ChatGPT deep-dive only; Gemini references TPS as the ancestor of Kanban/Hoshin/Six Sigma but has no standalone treatment.
- **Origin** `[FACT]`: Toyota / Taiichi Ohno, late 1940s–1970s; *The Machine That Changed the World* (MIT, 1990) spread "lean." [source: https://en.wikipedia.org/wiki/The_Machine_That_Changed_the_World_(book)]
- **Structure:** `Customer demand → pull flow → standardized work → detect abnormality → stop/fix → improve.`
- **SWOT (partial):** **S** among the most evidence-backed operating systems in management history · **W** "lean theater" — dehumanized cost-cutting under lean branding; copying tools without the problem-solving culture.
- **Case study:** **1997 Aisin fire** — Toyota's supplier network + operating discipline restored production far faster than expected (resilience property). [source: https://sloanreview.mit.edu/article/the-toyota-group-and-the-aisin-fire/]
- **Evidence** `[DIRECT]` — "one of the most durable management systems ever built."
