# EOS / Traction (Wickman)

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Gino Wickman; *Traction* (2007). [self-reported: https://www.eosworldwide.com/what-is-eos]
- **Structure — Six Components:** `Vision (V/TO) | People (right people/seats) | Data (weekly scorecard) | Issues (IDS) | Process (document core processes) | Traction (90-day Rocks + weekly Level 10 meetings).` [SIGNAL — "core 20%" claim unverified]
- **SWOT:** **S** exceptionally practical for founders going chaos→systems · **W** rigid ("do it exactly the EOS way"), weak process documentation · **O** Integrator/Visionary balance · **T** adopting the meetings but refusing to fix "wrong seats."
- **Use / fails:** 20–250-person companies hitting a growth ceiling; ⚠️ Gemini asserts it "fails beyond ~500 people" (a precise threshold ChatGPT doesn't support — soft claim). Too heavy stacked on mature OKR/scorecard systems.
- **Case study:** **Gold Leaf Farming** — Level 10 + IDS → financial/operational stabilization. `[COI — FRAMEWORK OWNER]` [self-reported: https://3ppartners.com/case-studies-the-impact-of-an-entrepreneurial-operating-system-eos-within-the-food-ag-industry/]
- **Evidence** `[INDIRECT]` — high SME efficacy, largely anecdotal/vendor-supplied.
