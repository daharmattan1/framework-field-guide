# Shape Up (Basecamp)

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Ryan Singer, Basecamp, 2019. [self-reported: https://basecamp.com/shapeup]
- **Structure:** `Shaping (bounded problem + appetite) → Pitch → Betting Table → 6-week build (no backlog, no standups) → Cool-down.` Appetite (fixed time, variable scope) replaces estimation.
- **SWOT:** **S** kills backlog fatigue, guarantees 6 weeks of deep work · **W** needs highly autonomous senior teams · **O** antidote to endless-2-week-sprint burnout · **T** teams that can't cut scope near the deadline → failed cycles.
- **Case study:** **Basecamp** ships major updates with no Scrum Masters/backlog grooming/sprint planning. `[COI — FRAMEWORK OWNER]` [self-reported: https://basecamp.com/shapeup]
- **Evidence** `[INDIRECT]` — relies on Basecamp's unique culture; owner-derived. **Conflict:** Scrum (rejects backlogs + sprints).
