# Kanban

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Toyota pull systems (1940s); adapted for knowledge work by David J. Anderson.
- **Structure:** `Backlog → To Do → In Progress (WIP-limited) → Review → Done`; visualize flow, limit WIP, pull not push.
- **SWOT:** shares the combined Agile SWOT; ChatGPT adds **S** operational honesty, low ceremony · **W** without service policies + review discipline, boards become "placid wallpaper."
- **Case study:** Knowledge-work Kanban pioneers: **Microsoft XIT Sustaining Engineering (2004)**, **Corbis (2006–2007)**, **Robert Bosch (2006)**.
- **Combine:** Theory of Constraints, DORA (flow bottlenecks). Evidence `[INDIRECT]` (ChatGPT) / folded into `[DIRECT]` Agile canon (Gemini).
