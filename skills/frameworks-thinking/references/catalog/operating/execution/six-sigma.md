# Six Sigma / DMAIC

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: Motorola, 1986; spread by GE, 1990s. [source: https://www.sixsigmaonline.org/six-sigma-history/]
- **Structure — DMAIC:** `Define → Measure → Analyze → Improve → Control.` Goal ≤3.4 defects/million.
- **SWOT:** **S** unparalleled for waste/cost/defect reduction in manufacturing · **W** crushes innovation (breakthrough R&D needs variance) · **O** optimizing mature commoditized lines (H1) · **T** universal application suffocates creative departments.
- **Case study — cautionary:** **3M (2000s)** — GE alum James McNerney rolled Six Sigma across R&D; margins spiked short-term but the **innovation culture choked; by 2007 3M dropped it from R&D and fell off innovation rankings.** [source: https://www.inc.com/linkedin/don-peppers/downside-six-sigma-don-peppers.html]
- **Conflict:** Agile, Design Thinking, Blue Ocean/GIST, Three-Horizons H3. Evidence `[DIRECT]` — success in operations, documented failure in innovation.
