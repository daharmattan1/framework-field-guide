# 4DX (4 Disciplines of Execution)

- **Layer / Taxon:** operating · execution
- **Origin** `[FACT]`: McChesney, Covey, Huling (FranklinCovey), 2012. [source: https://www.franklincovey.com/books/the-4-disciplines-of-execution/]
- **Structure:** `1. Focus on the Wildly Important (1–2 WIGs) → 2. Act on Lead Measures → 3. Compelling Scoreboard → 4. Cadence of Accountability (weekly 15-min).`
- **SWOT:** **S** solves the exact gap OKRs leave — weekly behavioral accountability · **W** can feel patronizing to autonomous eng teams · **O** execution engine beneath OKRs · **T** tracking lag measures as if they were lead measures.
- **Case study:** **Marriott Opryland** — behavioral lead measures + visible scoreboards → consistent execution. `[COI — FRAMEWORK OWNER]` [self-reported: https://www.slideshare.net/slideshow/opryland-case-study-video-franklin-covey-46400133/46400133]
- **Combine:** OKRs (OKRs set the destination, 4DX runs the engine). Evidence: Gemini `[DIRECT]`, ChatGPT `[INDIRECT]` (owner-promoted).
